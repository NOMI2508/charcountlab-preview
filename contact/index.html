Contact

Corrections, bug reports and questions about how the tools count are all welcome.

Email

Development build. A contact address has not been added to the site configuration yet, so there is no working way to get in touch from this copy of the site. A real, monitored address must be supplied before launch.

Reporting a wrong count

To check a problem we need to be able to reproduce it. It helps to include:

  • which tool and which number looked wrong, and what you expected instead;
  • a short piece of text that shows the problem. Please send an example you are happy to share, not private or confidential text;
  • your browser and device, since counting uses your browser’s own Unicode rules.

Reporting an out-of-date limit

Platforms change their limits without announcement. If a figure on the platform limits page is no longer right, a link to the platform’s current official documentation is the most useful thing you can send. Limits are only changed on the strength of an official or primary source.

Errors in guides

Tell us which guide and which statement, and point to a source if you have one. The editorial policy describes how corrections are handled.

What we cannot help with

This site does not send text messages and has no connection to any messaging provider, social platform or application system. Questions about a bill, a rejected post or a submitted form need to go to the service concerned.
