Character Counting

What a character count includes, and where counts go wrong.

What Counts as a Character? A Practical Guide

Every letter, digit, space, punctuation mark and line break normally counts as one character. Emoji, accented letters and some scripts are where counters start to disagree.

Character Count With Spaces vs Without Spaces

A count with spaces includes every space; a count without spaces leaves them out. If a limit says only "characters", assume spaces count, and check whether tabs and line breaks are treated as spaces.

Character Count vs Word Count: What’s the Difference?

Use characters when the space is fixed and words when the limit is about how much you say. The two do not convert reliably, and word counts themselves depend on how a tool defines a word.

How to Count Characters in Microsoft Word and Google Docs

In Word, click the word count in the status bar. In Google Docs, use Tools > Word count or Ctrl+Shift+C. The two programs do not count the same parts of a document, so check what is included.

How Line Breaks, Tabs and Spaces Affect Character Count

Whitespace counts. A space or a tab is one character, a line break is one on most systems and two on Windows, and zero-width characters count even though they are not whitespace at all.

Unicode & Technical

Code points, grapheme clusters, bytes and what software really measures.

Why Emoji Can Produce Different Character Counts

An emoji is one visible character, but it can be built from several Unicode code points, and from even more UTF-16 units or bytes. The number you get depends on the unit a system counts in.

Unicode Characters, Code Points and Grapheme Clusters Explained

A character can mean a code point, a code unit or a grapheme cluster. Only the last one matches what a reader sees. The other two describe how text is numbered and stored, which is why counts differ.

UTF-8 Bytes vs Characters: Why the Numbers Differ

In UTF-8 an English letter takes 1 byte, an accented letter 2, most Chinese, Japanese and Korean characters 3 and most emoji 4. A limit of 255 bytes can hold far fewer than 255 characters.

Why JavaScript String Length Can Be Misleading

The length of a JavaScript string is its number of UTF-16 code units, not characters. Use the string iterator for code points, Intl.Segmenter for visible characters and TextEncoder for bytes.

Characters, Bytes and Database Field Limits Explained

The n in VARCHAR(n) counts characters in MySQL and PostgreSQL, bytes by default in Oracle, bytes in SQL Server varchar and byte-pairs in nvarchar. Validate input in the unit your column uses.

SMS

Encodings, segments and the characters that change the size of a text message.

SMS Character Limits: GSM-7, Unicode and Message Segments

A single SMS holds 160 characters from the GSM 7-bit alphabet, or 70 if any character falls outside it. Longer texts are sent as parts of 153 or 67, and each provider sets its own cap on the number of parts.

Why One Emoji Can Change the Length of an SMS

No emoji is in the GSM 7-bit alphabet, so adding one sends the whole message as Unicode. The limit falls from 160 to 70, or from 153 to 67 per part, and most emoji then use two or more of those units themselves.

What Is GSM-7? A Simple Guide to SMS Encoding

GSM-7 is the default alphabet for SMS: 128 code positions of 7 bits each, which is how 140 bytes hold 160 characters. It covers basic Latin letters, digits and a few accents. Anything outside it forces the message into Unicode.

Why Some SMS Characters Count Twice

Ten characters in the GSM-7 extension table, including square brackets, braces and the euro sign, are sent as an escape code plus a second code. Each uses 2 of the 160 units, and the standard forbids dividing a pair between two parts.

Writing & Limits

Working to a limit: platforms, search results, forms and tight copy.

How to Write Clearly When You Have a Strict Character Limit

Write the full thought first, then cut in order: empty openers, noun phrases, spelled-out numbers, long words. Keep the one specific detail, because that is what a reader remembers.

Character Limits for Social Media: A Practical Reference

The limits for X, Instagram, LinkedIn and YouTube in one table, each linked to the official page it was checked against. Only X publishes how it counts characters; for the others, any counter is a close estimate.

SEO Title Length: Characters vs Pixel Width

Google documents no character limit and no pixel limit for titles. It says title links are truncated as needed, typically to fit the device width. The familiar character figure is a third-party rule of thumb, useful as a sanity check and nothing more.

Meta Description Length: Why Character Count Is Only a Guideline

Google says there is no limit on how long a meta description can be. Snippets are truncated as needed, typically to fit the device width, and are built primarily from page content. A character figure is a writing aid, not a guarantee.

How Character Limits Work in Online Forms and Applications

A form counts whatever its software counts: usually every letter, space and line break. Browsers measure in UTF-16 code units, line breaks can count twice, and servers may check bytes.
